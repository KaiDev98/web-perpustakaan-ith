# Website Perpustakaan ITH

Website informasi dan layanan permohonan Perpustakaan Institut Teknologi Bacharuddin Jusuf Habibie. Branch `Niyato` memuat dokumen Fase 0 dan fondasi backend Fase 1. Autentikasi admin dan fondasi frontend sedang dikembangkan secara lokal; modul konten dan layanan permohonan belum aktif.

Mulai dari [CODEX_START_HERE.md](CODEX_START_HERE.md), [kebutuhan](docs/REQUIREMENTS.md), [arsitektur](docs/ARCHITECTURE.md), dan [roadmap](docs/ROADMAP.md). Petunjuk menjalankan API/MySQL ada di [backend/README.md](backend/README.md), dan dua frontend lokal ada di [frontend/README.md](frontend/README.md).

Fase 1 telah mendapat izin commit dan push pada branch `Niyato`. Jangan memasukkan `.env`, data MySQL, secrets, log, atau `node_modules` ke Git.
